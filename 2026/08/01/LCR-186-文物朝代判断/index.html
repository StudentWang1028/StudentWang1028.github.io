LCR 186.文物朝代判断

题目链接

  • LeetCode：https://leetcode.cn/problems/bu-ke-pai-zhong-de-shun-zi-lcof/description/?envType=problem-list-v2&envId=8LSpuXqD
  • 难度：easy

初次解答

  1. 因为places的范围为0-13，因此用num记录出现次数，如果出现出现次数大于1次首先就不满足返回false;
  2. 记录当前剩余补充数、开始位置
  3. 如果当前不为开始位置,看num中该数是否出现过，出现过则num–，没出现过用zero代替，如果zero没有了，则不满足返回false

错误/踩坑

  • 忽略了可以在第一次非0数字前就进行补充的情况

优化方案

  • 按从小到大排序，记录zero次数
  • 如果存在重复数则返回false
  • 比较非0的最大数和最小数的范围是否在5之内

假设除去 0 之后，剩下的非零牌数为 $k$ 张（$1 \le k \le 5$），手中 0 的数量为 $5 - k$ 个。
假设除去 0 之后，剩下的非零牌数为 $k$ 张（$1 \le k \le 5$），手中 0 的数量为 $5 - k$ 个。

  1. 确定闭区间长度：
    在没有重复元素的前提下，若非零元素的最小值为 $\text{min}$，最大值为 $\text{max}$，则包含这两个端点在内的完整连续区间为 $[\text{min}, \text{max}]$。
    这个区间的总元素个数为：

    $$\text{区间长度} = \text{max} - \text{min} + 1$$

  2. 计算中间缺失的数字个数：
    既然区间内一共需要 $\text{max} - \text{min} + 1$ 个连续数字，而我们目前手中只有 $k$ 个非零数字，那么中间缺失的数字个数为：

    $$\text{缺失个数} = (\text{max} - \text{min} + 1) - k$$

  3. 用 0 填补空缺的条件：
    我们手中的 0 数量必须大于等于缺失的数字个数，即：

    $$5 - k \ge (\text{max} - \text{min} + 1) - k$$

    两边同时加上 $k$ 并化简：

    $$5 \ge \text{max} - \text{min} + 1 \implies \text{max} - \text{min} \le 4 < 5$$

复杂度分析

时间复杂度：O(nlogn)

空间复杂度：O(1)
