LCR 157.套餐内商品的排列顺序

John Doe
2026-08-01
leetcode
递归

题目链接

  • LeetCode：https://leetcode.cn/problems/zi-fu-chuan-de-pai-lie-lcof/description/?envType=problem-list-v2&envId=8LSpuXqD
  • 难度：mid

初次解答

  1. 由于题目限定字符串包含字母，可用长度为 26 的数组记录每个字符出现的频次。
  2. 采用回溯算法，从 'a' 到 'z' 遍历频次数组：
    • 遇到频次大于 0 的字符，将其加入 StringBuilder 并将频次 -1。
    • 递归进入下一层。
    • 回溯时恢复频次并将字符从 StringBuilder 中移除。

错误/踩坑

优化方案

  • 固定位置 + 交换：将字符数组分为“已固定部分”和“未固定部分”。
  • 递归函数 dfs(x) 的含义为：固定第 x 位的字符。同层剪枝去重：在固定第 x 位时，遍历可选的后方字符 c[i] (i≥xi \ge xi≥x)。若当前字符在第 x 位已经出现过，则跳过（剪枝），否则将其交换至第 x 位。
  • 回溯恢复：下层递归结束后，再次交换恢复原状。

复杂度分析

时间复杂度：O(n·n!)

空间复杂度：O(n)
