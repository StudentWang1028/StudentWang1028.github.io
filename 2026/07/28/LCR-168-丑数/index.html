LCR 168.丑数

John Doe
2026-07-28
leetcode
剑指Offer, 动态规划, 多指针

题目链接

  • LeetCode:https://leetcode.cn/problems/chou-shu-lcof/?envType=problem-list-v2&envId=8LSpuXqD
  • 难度：Mid

初次解答

  1. 采用动态规划+三指针；
  2. 丑数只能由已有丑数乘以 2、3、5 生成，使用三个指针 index2、index3、index5 分别维护乘以 2、3、5 后的候选位置。
  3. 状态转移：每次选择三个候选值中的最小值作为下一个丑数。，dp[i] = min(dp[index2]*2,dp[index3]*3,dp[index5]*5)，对应取值的index值更新

错误/踩坑

使用 else if 更新指针导致重复丑数。

例如：2 × 3 = 3 × 2 = 6
当 next = 6 时：

  • index2 对应生成 6
  • index3 对应也生成 6
    如果只移动 index2，index3 仍然保留旧位置，下一轮会再次生成 6。

因此三个指针需要分别判断：

  • next == next2，index2++
  • next == next3，index3++
  • next == next5，index5++

优化方案

复杂度分析

时间复杂度：O(n)

  • 需要生成 n 个丑数，每次生成只需要比较三个候选值，因此每轮 O(1)。

空间复杂度：O(n)

  • 使用 dp 数组保存已经生成的所有丑数。
