LCR 168.丑数

John Doe
2026-07-28

🔗 题目链接

  • 难度：Hard

💡 初次解答

  1. 采用递归
  2. 每个位置可以放2，3，5
  3. 终止条件是当前值大于等于目标值

‘’’java
class Solution {
public int nthUglyNumber(int n) {
return isUglyNumber(n,1);
}
public boolean isUglyNumber(int n,int curr){
if(curr>n) return false;
if(curr==n) return true;
if(isUglyNumber(n,curr2)||isUglyNumber(n,curr3)||isUglyNumber(n,curr*5)) return true;
return false;
}
}
‘’’

🚀 优化点

  • 当 curr 乘以 2、3 或 5 时，结果可能超出 int 范围（变为负数或 0）.
  • 该算法本质是枚举所有形如 2^a * 3^b * 5^c 的数，直到超过目标值，对于较大的 n，会指数级地产生大量无效分支。
    ‘’’java
    class Solution {
    public int nthUglyNumber(int n) {
    if(n<=0) return false;
    while(n%5==0) n = n/5;
    while(n%3==0) n = n/3;
    while(n%2==0) n = n/2;
    return n==1;
    }
    }
    ‘’’
