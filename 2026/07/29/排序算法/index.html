排序算法

1. 排序算法概述

排序（Sorting）是将一组无序的数据按照某种规则重新排列，使其满足递增或递减关系的过程。
例如：

排序算法广泛应用于：

  • 数据库索引
  • 搜索优化
  • Top K问题

2. 排序算法分类

2.1 比较类排序

通过比较两个元素的大小决定排序结果。
特点：

  • 通用性强
  • 时间复杂度通常不低于 O(nlogn)

主要算法：

算法 核心思想 适合场景
冒泡排序 相邻元素比较交换，每轮将最大值移动到末尾 数据量小、教学场景，实际工程较少使用
选择排序 每轮寻找最小元素放入当前有序区间 数据量小、交换次数要求少的场景
插入排序 将元素插入已有序区间，逐渐扩大有序范围 数据基本有序、数据规模较小时效率较高
快速排序 选择基准元素，通过分区将数组划分为左右两部分递归排序 通用数组排序，平均性能优秀
归并排序 分治拆分数组，再合并两个有序数组 要求稳定排序、链表排序、逆序对统计
堆排序 利用堆结构不断取出最大/最小元素 Top K问题、优先队列、空间要求严格的排序

2.2 非比较类排序

不通过比较元素大小，而利用数据本身特点。
主要算法：

算法 核心思想 适用场景
计数排序 统计每个元素出现次数，根据频率恢复排序结果 数据范围较小、整数排序
桶排序 将元素划分到多个桶中，每个桶内部排序后合并 数据分布均匀、范围较大的浮点数排序
基数排序 按照数字的每一位进行排序，从低位到高位逐步完成整体排序 整数、字符串等具有固定位数的数据排序

3. 排序算法复杂度对比

排序算法 平均时间 最好情况 最坏情况 空间复杂度 稳定性
冒泡排序 O(n²) O(n) O(n²) O(1) 稳定
选择排序 O(n²) O(n²) O(n²) O(1) 不稳定
插入排序 O(n²) O(n) O(n²) O(1) 稳定
快速排序 O(nlogn) O(nlogn) O(n²) O(logn) 不稳定
归并排序 O(nlogn) O(nlogn) O(nlogn) O(n) 稳定
堆排序 O(nlogn) O(nlogn) O(nlogn) O(1) 不稳定

4. 稳定性

什么是稳定排序？

如果两个元素值相同：排序前、后相对顺序保持不变，则称为稳定排序。

稳定排序：

  • 冒泡排序
  • 插入排序
  • 归并排序
  • 计数排序

不稳定排序：

  • 快速排序
  • 选择排序
  • 堆排序

5.1 核心思想

不断比较相邻元素：如果前一个元素 > 后一个元素，交换两个元素。每一轮结束，当前最大元素移动到数组末尾。

6.1 核心思想

每次从待排序的数据中选择最小（或最大）的元素，放到已排序序列的末尾，直到全部数据排序完成。

  • 最坏 O(n²)

7. 插入排序 Insertion Sort

7.1 核心思想

维护一个有序区间,每次取一个新元素，插入到正确位置,类似整理扑克牌。

7.2 示例

7.3 Java实现

7.4 复杂度

时间复杂度：

  • 最好 O(n),当列表已经有序时，只需遍历一次列表
  • 平均 O(n²)
  • 最坏 O(n²),当列表是逆序时，每次插入都需要移动所有已排序元素

空间复杂度：O(1)

8. 希尔排序 Shell Sort

8.1 核心思想

先将整个待排序的记录序列分割成为若干子序列分别进行直接插入排序，待整个序列中的记录”基本有序”时，再对全体记录进行依次直接插入排序。

8.2 示例

8.3 Java实现

8.4 复杂度

时间复杂度：

  • 最好 O(n)，当增量序列选择合适时
  • 平均 O(n log n) 到 O(n²) 之间
  • 最坏 O(n²)，当增量序列选择不当时、

常见的增量序列：

  • 希尔增量：n/2, n/4, …, 1，时间复杂度为 O(n²)。
  • Hibbard 增量：1, 3, 7, 15, …, 2^k - 1，时间复杂度为 O(n^(3/2))。
  • Sedgewick 增量：1, 5, 19, 41, 109, …，时间复杂度为 O(n^(4/3))。

空间复杂度：O(1)

9. 归并排序 mergeSort

9.1 核心思想

归并排序的核心思想是将一个大问题分解成若干个小问题，分别解决这些小问题，然后将结果合并起来，最终得到整个问题的解。具体到排序问题，归并排序的步骤如下：

  1. 分解（Divide）：将待排序的数组分成两个子数组，每个子数组包含大约一半的元素。
  2. 解决（Conquer）：递归地对每个子数组进行排序。
  3. 合并（Combine）：将两个已排序的子数组合并成一个有序的数组。
    通过不断地分解和合并，最终整个数组将被排序。

9.3 Java实现

9.4 复杂度

时间复杂度：O(nlogn)

  • 分治法；一共logn层，每层n个元素

空间复杂度：O(n)

  • 归并过程中需要额外数组 temp 保存合并结果

11. 堆排序 Heap Sort

11.1 核心思想

堆积是一个近似完全二叉树的结构，并同时满足堆积的性质：即子结点的键值或索引总是小于（或者大于）它的父节点。堆排序可以说是一种利用堆的概念来排序的选择排序。分为两种方法：

  • 大顶堆：每个节点的值都大于或等于其子节点的值，在堆排序算法中用于升序排列；
  • 小顶堆：每个节点的值都小于或等于其子节点的值，在堆排序算法中用于降序排列；

11.2 示例

假设有一个待排序的列表 [4, 10, 3, 5, 1]，堆排序的过程如下：

  1. 构建最大堆：
    1.1 初始列表：[4, 10, 3, 5, 1]。
    1.2 从最后一个非叶子节点开始，逐步调整堆：
    1.3 调整节点 5：[4, 10, 3, 5, 1]（无需调整）。
    1.4 调整节点 10：[4, 10, 3, 5, 1]（无需调整）。
    1.5 调整节点 4：[10, 5, 3, 4, 1]。
    1.6 最终最大堆：[10, 5, 3, 4, 1]。

  2. 交换堆顶元素：
    2.1 将堆顶元素 10 与最后一个元素 1 交换，列表变为 [1, 5, 3, 4, 10]。
    2.2 堆的大小减 1，已排序部分为 [10]。

  3. 调整堆：
    3.1 对新的堆顶元素 1 进行下沉操作：
    3.2 比较 1 和其子节点 5、3，将 1 与 5 交换。
    3.3 列表变为 [5, 1, 3, 4, 10]。
    3.4 继续比较 1 和其子节点 4，将 1 与 4 交换。
    3.5 列表变为 [5, 4, 3, 1, 10]。
    3.6 调整后的堆：[5, 4, 3, 1]。

  4. 重复步骤.

时间复杂度：O(nlogn)

  • 每次调整堆：O(log n)，总共需要调整 n-1 次。

空间复杂度：O(1)

12. 计数排序 Counting Sort

12.1 核心思想

通过统计每个元素的出现次数，然后根据统计结果将元素放回正确的位置。

12.2 示例

12.3 Java实现

12.4 复杂度

时间复杂度：O(n + k)，其中 n 是列表长度，k 是数据的范围大小

  • 统计频率：O(n)，遍历列表一次。

  • 累加频率：O(k)，遍历计数数组一次。

  • 放置元素：O(n)，遍历列表一次。

空间复杂度：O(n+k),需要额外的计数数组和结果数组

13. 桶排序 Bucket Sort

13.1 核心思想

将待排序的元素分配到若干个桶（Bucket）中，然后对每个桶中的元素进行排序，最后将所有桶中的元素按顺序合并。桶排序的核心思想是将数据分到有限数量的桶中，每个桶再分别排序（可以使用其他排序算法或递归地使用桶排序）。

13.2 示例


13.3 Java实现

13.4 复杂度

时间复杂度：O(n + k * m log m)，其中 n 是列表长度，k 是桶的数量，m 是每个桶的平均元素数量

  • 分配元素：O(n)，遍历列表一次。

  • 排序每个桶：假设每个桶中的元素数量为 m，则排序一个桶的时间复杂度为 O(m log m)。如果桶的数量为 k，则总时间复杂度为 O(k * m log m)。

  • 合并桶：O(n)，遍历所有桶一次。

空间复杂度：O(n + k)，需要额外的存储空间来存放桶和排序后的结果

14.1 核心思想

将整数按位数切割成不同的数字，然后按每个位数分别进行排序。
